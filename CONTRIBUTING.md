# Contributing to Archon

Archon is at the project-foundation stage. Contributions that clarify the
problem, mathematics, and reproducible development plan are especially useful.

## Before contributing

- Treat Anchor's equations and Archon's architecture as undecided unless they
  are explicitly recorded as accepted in the documentation.
- Label proposals as proposals; do not present unreviewed formulas or
  performance claims as established results.
- Include a source or derivation for mathematical claims.
- Include data provenance and license details for proposed training data.

## Changes

Keep mathematical specification changes separate from implementation changes
where practical. When an implementation is added, include small reference
examples and tests that connect it to the written specification.

The project uses the MIT License. Contributions are submitted under that
license.
